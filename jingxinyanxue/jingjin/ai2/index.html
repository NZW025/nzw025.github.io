Categories

 Computer Vision: Enables machines to make sense of visual content such as images and videos

 Natural Language Processing: Enables machines to understand and generate human language

 Recommendation System: A system that recommends content (such as products, videos, and so on) that users are interested in

 Embodied Intelligence: Enables AI systems to interact with the environment by integrating physical entities (such as robots)

Core Process of AI (from Data to Prediction) A simple process
1. Train the model with historical data
2. Input new data into the trained model
3. The model completes the prediction and derives the unknown attributes of the data

Key Elements of AI To implement AI, three core components are needed:
 Model: An algorithmic framework for processing data and completing tasks
 Data: The "raw material" for training and validating the model  Computing Power Platform: Hardware resources that support model training and running

Concepts Related to ChatGPT

 Meaning of GPT

 G → Generative (Generative, capable of generating text, images, and so forth)
 P → Pre-trained (Pre-trained, the model first undergoes basic training on vast amounts of data)
 T → Transformer (A deep learning architecture based on the "attention mechanism", which is the core technology of large models)
 Model Training Process: Pre-training → Post-training (Fine-tuning, to adapt the model to specific tasks)

Core Elements of Large Models
 Technical Support: Large Model + Big Data + Big Computing ("Three Bigs" form the foundation of large models)

1. Functions of Large Models
 Dialogue, Consultation (Analysis of Experience Outcomes)
 Legal, Writing (Technical Reports, Academic Papers), Document Processing, Drawing
 Video Generation (such as Sora), Audio Generation, and the breakthrough of "seeing is believing" rather than "hearing is deceitful"

2. Working Principle
 Core Logic: NTP (Next Token Prediction, "Next Token Prediction", where the model generates coherent text by predicting subsequent content)
